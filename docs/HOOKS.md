Память не является полным архивом всех new/edit/delete/difference: ранние hooks охватывают стандартные edit/delete/history update types только для уже созданных карточек и пока не имеют входного WAL. `MessagesStorage`, входящие seq/pts/qts и общий MTProto callback не изменены. Обычный read cursor работает штатно; typing, обычный online-status и content-read входящих voice/round video ограничены описанными semantic paths. Подробные собственные API, guarantees и оставшиеся crash/network проверки — в `MEMORY.md`, `PRIVACY.md`, `PROXY.md`, `APPEARANCE.md` и `TESTING.md`.
