# Текущие ограничения

Полное ТЗ пока не выполнено. Данная ветка начинает реализацию; список функций со статусами — в `FEATURE_PARITY.md`.

Нет предоставленных собственных Telegram API-данных, Firebase, release keystore, доверенного прокси-пула/HTTPS endpoint и серверов. Разработческий APK может собираться без них, но вход, FCM и готовое соединение через прокси не подтверждаются. Телефонные коды и 2FA вводятся только пользователем в приложении.

Полный автоматический архив, отдельный локальный read cursor, полный ghost mode, подписанный APK-updater, P1-комфорт и P2-плагины не объявляются готовыми. В экспериментальной приватности реализовано account-local подавление обычных typing/recording/upload/sticker/emoji activity actions и foreground online-status. Сохранение явно защищённого/одноразового/секретного содержимого, чужие официальные API-ключи и имитация серверного Premium исключены из требований.

Пункт 1.4 [правил Telegram API](https://core.telegram.org/api/terms) прямо конфликтует с подавлением online/read/typing. Выключенный тумблер или отдельный flavor не устраняют этот конфликт. Невидимость при отправке, звонке и другой активной сессии не гарантируется.

Прокси не восстанавливает никогда не полученный текст и не гарантирует доступность при полной изоляции сети. Сохранение карточек не означает бесконечное хранение или восстановление потерянного ключа. Именование MOROK и товарные знаки перед публичным магазинным релизом требуют отдельной проверки совпадений; регистрация доменов не выполнялась.
