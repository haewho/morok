# Локальные имена и заметки чатов

Для обычного личного чата, группы или канала в меню `⋮` доступно действие «Локальное имя и заметка». Общий список с поиском, редактированием и очисткой находится в MOROK Settings → «Имена и заметки чатов». Псевдоним меняет только заголовок открытого чата на этом устройстве. Имя профиля, контакт и данные на серверах Telegram не меняются. Значки verified/scam/fake/premium и штатный subtitle устанавливаются Telegram как раньше: MOROK заменяет только текст уже построенного заголовка.

Заметка видна только в отдельном локальном редакторе. Секретные чаты, «Сохранённые сообщения», Replies/Anonymous и служебные режимы исключены. Для forum topics используется одна запись обычного dialog ID, поэтому локальные данные относятся ко всей группе, а не к отдельной теме.

## Хранение и границы

- Пространство привязано к устойчивому Telegram user ID, а не к повторно используемому номеру account slot.
- До 256 непустых записей на аккаунт; псевдоним до 64 символов, заметка до 4096 символов, весь открытый документ до 1 МиБ.
- JSON существует только в памяти. На диск в `noBackupFilesDir/morok/chat-metadata/<userId>/metadata.tink` атомарно пишется ciphertext Google Tink AES-GCM через Android Keystore.
- Отдельный ключ `morok.chatmeta.v1.<stableUserId>` и AAD с версией, user ID и назначением не позволяют перенести ciphertext в другое пространство аккаунта.
- Если ключ потерян при существующем ciphertext, новый ключ молча не создаётся. Ошибка показывается пользователю, зашифрованный файл сохраняется для диагностики.
- Logout сначала синхронно фиксирует durable revocation marker, затем удаляет ключ и каталог. Новый пользователь в том же Telegram account slot не получает старые данные.
- Редактор и store не используют `ConnectionsManager`, `SendMessagesHelper` или Telegram messages database. Данные исключены из штатного backup и из переноса настроек MOROK.

Это локальное удобство, а не скрытие серверной личности: собеседник продолжает видеть настоящий профиль, а уведомления, список чатов, поиск и forward headers пока используют штатные Telegram-названия. Полная проверка требует авторизованного аккаунта и сценария logout/login на устройстве.
