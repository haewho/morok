# Морок / MOROK

Утверждённое имя: **Морок** по-русски, **MOROK** латиницей. Утверждённый знак — **Личина**: вертикальная симметричная фиолетовая маска с заострённым верхом, прорезью во лбу, двумя глазами и ступенчатым заострённым низом.

Приложение использует аккаунты, серверы и протокол Telegram. В «О приложении» требуется формулировка «Неофициальный клиент, использующий Telegram API», версия исходной базы и её авторские/лицензионные уведомления. Личина — современная художественная стилизация; историческое происхождение конкретного знака не заявляется.

## Источник и палитра

Владелец предоставил отдельный референс `morok.png`, 1254 × 1254 px. SHA-256: `258fb62aa50ad46ddc7fa5488f4d5f6f03615d8f3af1180c391dd610125a366a`. Мастер вручную восстановлен редактируемыми кривыми Bézier: сохранены пропорции, симметрия, три прозрачные прорези и ступени. Небольшая фактура исходного растра заменена плоскими заливками согласно ТЗ. Это геометрическая реконструкция, не заявление о побитовом совпадении исходного растра.

Имена и палитра централизованы в [`assets/morok/brand.json`](../assets/morok/brand.json). Цвет основного знака выбран по центральным пикселям предоставленного изображения.

| Назначение | Цвет |
| --- | --- |
| Основной фиолетовый, тёмные поверхности | `#AE82FD` |
| Графитовый фон | `#111111` |
| Фиолетовый для светлого фона | `#7546BD` |
| Светлый фон | `#F6F2FA` |

Основная launcher-версия всегда использует фиолетовый на графитовом. Светлая версия предназначена для светлых поверхностей и материалов. Тематическую системную иконку окрашивает Android; её монохромный слой содержит только силуэт и прозрачные прорези.

## Ресурсы

| Путь | Назначение |
| --- | --- |
| `assets/morok/morok-master.svg` | Каноническая редактируемая геометрия на прозрачном фоне |
| `assets/morok/morok-dark.svg` | Основная версия на графитовом фоне |
| `assets/morok/morok-light.svg` | Версия для светлого фона |
| `assets/morok/android/drawable/morok_launcher_foreground.xml` | Android VectorDrawable с прозрачными прорезями |
| `assets/morok/android/drawable/morok_launcher_background.xml` | Отдельный графитовый фон |
| `assets/morok/android/drawable/morok_launcher_monochrome.xml` | Системный монохромный слой |
| `assets/morok/android/mipmap-anydpi-v26/` | Adaptive icon и round icon для API 26+ |
| `assets/morok/android/mipmap-anydpi-v33/` | Те же иконки с явным `monochrome` для API 33+ |
| `assets/morok/android/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/` | Квадратные и круглые PNG: 48, 72, 96, 144, 192 px |
| `assets/morok/android/values/morok_brand.xml` | Генерируемые Android-имя и цвета |
| `assets/morok/android/values-ru/morok_brand.xml` | Русское имя |
| `assets/morok/previews/` | Превью, сведения о геометрической проверке и rasterizer |

Каталог `assets/morok/android/` имеет структуру Android `res`: его можно подключить отдельным каталогом ресурсов существующего модуля либо перенести с сохранением путей. Для основной иконки используются `@mipmap/morok_launcher`, для круглой — `@mipmap/morok_launcher_round`, для подписи — `@string/morok_brand_name`. Сгенерированные XML и PNG не редактируются вручную. Интеграция с manifest, launcher aliases и splash проверяется отдельно от подготовки ресурсов.

Foreground имеет viewport 108 × 108 dp. Форма пропорционально вписана в область x=32.9599…75.0401, y=22…86 dp; её высота 64 dp. Прорези реализованы `evenOdd`, а не закрашены фоном. Это позволяет менять фон и использовать монохромный слой. В API 26-ресурсе нет элемента `monochrome`; он добавлен отдельным API 33-ресурсом. Требования слоёв и системных масок сверены с [документацией Android](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive) 6 сентября 2026 года.

## Воспроизводимость

После изменения геометрии мастера либо `brand.json` из корня проекта:

```sh
python3 assets/morok/generate_assets.py
node assets/morok/rasterize.cjs
```

Первый шаг использует только стандартную библиотеку Python и формирует SVG/Android XML. Второй использует установленный пакет `sharp` с поддержкой SVG через libvips/librsvg; он создаёт fallback PNG и превью. `NODE_PATH` может указывать на внешний каталог установленного `sharp`. Скрипт не скачивает зависимости и не изменяет исходный PNG.

При подготовке этих ресурсов использовался bundled Node.js Codex и `sharp`; точные версии записаны в `assets/morok/previews/rasterizer.json`. Если rasterizer недоступен, остаются готовые PNG и воспроизводимая векторная геометрия; не заменять экспорт вручную изменённым референсом.

- Контур проверен выборкой точек кривых: максимальное расстояние от центра adaptive-слоя 32 dp при безопасном радиусе 33 dp. Результат: `assets/morok/previews/verification.json`.
- Отрендерены 10 launcher PNG и 3 превью; размеры каждого проверены rasterizer.
- Визуально просмотрены основная иконка и круглая/скруглённая/светлая/монохромная маски. Верх, ступенчатый низ и прорези не обрезаны. Превью 16/24/32/48/64 px показывает сохранение узнаваемого силуэта; на 16 px тонкая детализация прорези во лбу ожидаемо ограничена числом пикселей.

Генератор ресурсов не подтверждает сборку APK, установку, работу launcher конкретного устройства или splash. Эти проверки входят в приёмку сборки. Доступность имени в магазинах/доменах и возможные совпадения ещё не исследованы.

## Правила применения и обновления

Сохранять пропорции и прозрачные прорези. Не добавлять подпись, градиент, тени, древесную фактуру, мелкий орнамент или дополнительные символы внутрь launcher icon. Не заменять Личину бумажным самолётиком. Сам SVG-мастер не содержит фона: фон отдельного варианта задаётся при экспорте.

В пользовательских собственных поверхностях используется Морок / MOROK: launcher, приветствие, настройки мода, уведомления, «О приложении», имена APK и описания релизов. Упоминания Telegram в технических объяснениях, API и лицензиях сохраняются. Стабильный `applicationId` задаётся конфигурацией сборки и не меняется ради обновления оформления.

После переноса upstream проверить основной launcher icon, `roundIcon`, все доступные launcher aliases/альтернативные иконки, splash, оба локализованных имени и подпись обновления. Проверять установку рядом с официальным Telegram, круглый и скруглённый launcher, системную тематическую иконку и обновление поверх предыдущего APK. Проверка геометрии SVG не заменяет эти проверки на устройстве.
