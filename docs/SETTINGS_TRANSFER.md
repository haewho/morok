# Перенос настроек

Экран **Настройки Морока → Перенос настроек** использует системный Storage Access Framework. Экспорт создаётся только по явному действию пользователя, импорт сначала разбирается и показывает список фактически изменяемых значений. До подтверждения ни одно значение не записывается, сетевые запросы и серверные настройки Telegram не затрагиваются.

Формат `MOROK_SETTINGS_PROFILE`, версия 5, — небольшой детерминированный UTF-8 файл `key=value`. Декодер принимает только полный набор известных полей, точные `true`/`false`, одну из трёх плотностей, размеров аватара и интервалов превью списка, известный профиль кружочков и поддержанную версию формата. Повторные и неизвестные ключи, неполный файл и ввод больше 16 КиБ отклоняются целиком. Строгий импорт версий 1–4 поддержан: отсутствующая в v1 плотность, отсутствующий до v3 размер аватара, отсутствующие до v4 секунды и отсутствующий до v5 интервал получают безопасные стандартные значения; следующий экспорт записывает версию 5.

Переносятся:

- Liquid Glass, уменьшение эффектов, плотность списка чатов, размер его аватаров, интервал двух строк превью и секунды недавнего времени;
- включение и профиль экспериментального качества кружочков;
- восемь глобальных переключателей экспериментальной приватности текущего авторизованного аккаунта.

Не переносятся Telegram-сессия, ID аккаунта, ID и исключения чатов, список автоархива, Memory и вложения, прокси/пароли, API/Firebase/signing keys, темы Telegram и настройки энергосбережения. Импорт сохраняет локальные исключения чатов аккаунта назначения. Поэтому один файл можно осознанно применить к другому собственному аккаунту без копирования его идентификаторов.

Текущая версия не экспортирует темы Telegram, карточки/архив и именованные наборы профилей. Для них нужны отдельные форматы и экраны; нельзя добавлять их в этот файл без новой версии формата и миграции.
