# Проверки

`scripts/check.sh` запускает доступные изолированные MOROK-тесты, сверку submodule SHA и whitespace checks. Они не заменяют полный Android build или устройство. Сборка чистой базы идёт отдельно от модификаций; текущие логи и результаты перечислены в `PROGRESS.md`.

До повседневной беты обязательны:

1. Установка рядом с Telegram: package, provider authorities, AccountManager contacts, deep links, launcher aliases. Обновление поверх предыдущего APK с той же подписью.
2. С собственными API-данными: вход/2FA, два аккаунта, текст, голосовые/видеосообщения, вложения, правки, реакции, группы, темы, камера и уведомления.
3. Память: включить автоархив только для тестового чата; разрешённый текст и полученный файл → автоматическая карточка → ручное закрепление/заметка/тег/напоминание → правка/удаление со второго аккаунта → принудительно остановить процесс между `journal.tink` и `cards.tink` → рестарт → replay, поиск, напоминание и правильный контекст. Вызвать offline catch-up через global/channel difference, включая new→edit→delete в одной последовательности и channel difference too-long snapshot; убедиться, что обычные `pts/qts/seq` продолжают двигаться. Отдельно импортировать локальный чат, проверить лимит 100, дедупликацию повторного импорта и отсутствие MTProto/media requests. На Wi-Fi/mobile проверить never/Wi-Fi/any policy, размеры 1/4/8 МиБ и метаданные при пропущенном оригинале. Уменьшить 30/90/180/365-дневный срок и 64/128/256-МиБ бюджет: после подтверждения удаляются только старейшие автоматические карточки, ручные остаются, UI показывает байты до/после. Для отсутствующего оригинала сначала проверить cache-only retry без сетевого запроса, затем скачать его штатно и повторить; состояние и счётчики хранилища должны обновиться. Две версии с одинаковыми байтами должны иметь две ссылки на один blob, который удаляется только после последней ссылки. Затем очистить обычный кеш. Повторить с одной миниатюрой, noforwards/secret/TTL, повреждённым journal ciphertext, overflow >256, logout и другим пользователем в том же слоте.
4. Потеря Keystore, низкое место, kill во время записи, повторы событий и массовые операции. Не объявлять сохранённым файл до атомарной записи действительных байтов.
5. Каждый режим оформления сначала открыть и отменить на preview, затем применить и проверить точные Liquid Glass/animation значения и определение «Свой режим» после ручного изменения. Liquid Glass on/off в открытом чате: прокрутка/черновик, attachment/menu/navigation, светлая/тёмная тема, большой шрифт, TalkBack. Измерить отсутствие работы renderer на покрытых отключённых поверхностях.
6. Прокси до входа: ручной импорт и авто-выбор, отказ одного узла, смена Wi-Fi/mobile, отсутствие direct fallback. Звонки/FCM/mini apps проверяются отдельно.
7. Собственное устройство arm64 и отдельная российская сеть: записать дату, модель/API, оператор, Wi-Fi/mobile, каждый транспорт и результаты. Эмулятор не заменяет эти проверки.
8. Перенос настроек: экспортировать файл через системный picker, проверить отсутствие auth/account/chat/proxy/archive/Memory полей, изменить несколько локальных параметров, импортировать файл и сверить preview до подтверждения. Проверить Cancel, неподдержанную версию, повторный ключ, обрезанный и слишком большой файл; после применения убедиться, что исключения чатов сохранились, server read cursor не отправился и настройки пережили рестарт.
9. Диагностика кружочков: по умолчанию журнал пуст и выключен; после opt-in записать OFF baseline и каждый профиль, проверить plan/preview/output/bitrate/encoder и Camera2 request/fallback. Отчёт не должен содержать ID аккаунта/чата, media bytes или путь файла. Скопировать только явной кнопкой, затем очистить и подтвердить нулевой счётчик.
10. Профили приложения: до входа проверить экран и отказ сохранения/применения. После входа открыть preview и Cancel для каждого режима, затем применить и сверить оформление, video/GIF autoplay, все privacy-флаги и notification content. Убедиться, что качество кружочков, direct/manual/auto route и chat exceptions не изменились; «Свой» переживает рестарт, «Предыдущие» возвращают состояние. Получить FCM для private/group/channel/story при скрытом тексте, проверить lock screen, открытое приложение, второй аккаунт и отсутствие исходящего read/online/server-notification request. Имитировать ошибку записи и kill между хранилищами отдельно.
11. Безопасность: при выключенном режиме убедиться в штатном screenshot. Включить защиту и проверить `FLAG_SECURE`, чёрный/пустой screenshot, screen recorder и recent-task preview; повторить для main, bubble, external share, PhotoViewer, story SurfaceView, translate и payment, затем после cold restart. Штатный passcode/noforwards secure не должен сниматься при выключении MOROK-флага. Для подтверждения звонка выдать/отклонить microphone/camera permissions, проверить Cancel/Back/double tap и положительный private audio/video call; incoming и group calls остаются штатными. Для подтверждения кружочка проверить, что OFF отправляет обычным жестом, ON открывает штатный preview, Cancel ничего не отправляет, а Send отправляет один round video; повторить с lock, trim, schedule, story reply, одноразовым режимом и каждым quality-профилем. Повторить на физическом устройстве производителя.
12. Жесты: после входа выбрать обычную и custom быструю реакцию штатным picker. При включённом MOROK-флаге двойное нажатие добавляет/удаляет выбранную реакцию; при выключенном не отправляет reaction request и не меняет сообщение. Проверить private/group/channel/forum, недоступную реакцию и второй аккаунт. Long press, явная кнопка реакций и двойной tap для zoom/seek в media viewer должны остаться штатными. Профили приложения, импорт настроек и reset жестов не должны менять выбранный эмодзи.
13. Диагностика: до входа проверить сведения о сборке/устройстве и прокси, явное отсутствие account-local данных и копируемый отчёт. После входа сверить число выбранных чатов, карточек/версий/файлов и размер Памяти с отдельными экранами; проверить loading/error/capture-gap. Во время чтения переключить/удалить аккаунт: старый результат не должен появиться. В clipboard не должно быть user/chat/message ID, содержимого карточек, путей или endpoint/credentials прокси. Переходы в соединение, архив, Память и кружочки не меняют состояние сами по себе.
14. Локальные данные чата: в private/group/channel задать псевдоним и многострочную заметку, закрыть/открыть чат и перезапустить приложение; заголовок должен использовать alias, а verified/scam/fake/premium icon и subtitle — остаться штатными. Очистить запись и увидеть исходное имя. Проверить один dialog через forum topic, лимиты 64/4096 и 256 записей, повреждённый ciphertext, потерю Keystore, низкое место и смену аккаунта во время async read. Пункт не должен появляться в secret/Saved/Replies/Anonymous, а proxy/network log — содержать запрос из editor. После logout войти другим пользователем в тот же slot и подтвердить отсутствие старых данных.
15. Шаблоны ответов: создать, изменить, найти и удалить plain-text шаблон; перезапустить приложение и проверить сохранность. Проверить `{name}`, `{first_name}`, `{date}`, `{time}` в private/group/channel/topic, с локальным alias, русским/английским языком и 12/24-часовым форматом; неизвестный токен должен остаться видимым, `{{name}}` — стать литеральным `{name}`. До изменения composer должен появиться preview подставленного результата; Cancel ничего не вставляет. После подтверждения проверить пустое поле, начало/середину/конец существующего draft и соседство с whitespace; выделенный текст должен остаться, cursor переместиться после вставки, а сообщение не должно отправиться до отдельного Send. Проверить отказ без изменения draft при превышении message limit, long-press delete, clear-all, 100 записей, границы 64/4096, повреждённый ciphertext, key loss и logout/login другого пользователя. Пункт не появляется в secret/Saved/Replies/Anonymous/read-only channel/service modes.
16. Обновления приложения: development APK без `morok-update-trust.properties` показывает unconfigured и не делает сеть. Для двух последовательных release APK с одним постоянным signer проверить signed manifest через primary, fallback backup и unexpired cache; newer version отображает точный changelog/base/commit. Отдельно подменить signature, payload, version reuse, rollback, timestamps, package, ABI, size, APK SHA-256, APK version и signer — файл должен быть отвергнут до installer. Проверить отсутствие redirects и фоновых checks, отмену/уход во время download, unknown-sources permission, Android confirmation, сохранность MOROK settings/Memory после upgrade и отсутствие фиктивного downgrade.
17. Сохранённые черновики: в private/group/channel/topic набрать plain text с пробелами и переносами, сохранить снимок, изменить штатный draft, закрыть/перезапустить приложение и восстановить. При непустом редакторе Cancel сохраняет текущий текст, Replace заменяет только текст и ничего не отправляет; reply/topic остаются прежними. Проверить overwrite/delete, 256 destinations, границы 128/4096, слишком длинный restore, повреждённый ciphertext, key loss, logout/login другого пользователя и смену аккаунта во время async I/O. Пункт не появляется в secret/Saved/Replies/Anonymous/read-only channel/service modes.
18. Частичное выделение: долгим нажатием выделить часть plain text/caption, изменить границы обоими handles, проверить Copy/Select All/Quote/Translate и новое «Вставить в редактор». Вставить в начало/середину/конец непустого draft, проверить whitespace, emoji/RTL и отказ по message limit без изменения поля. В secret, TTL, peer/message noforwards, Saved/Replies/Anonymous/read-only/service режимах MOROK action отсутствует; штатные запрещённые действия не появляются. До отдельного Send запрос отправки отсутствует.

Невыполненные тесты не маркируются passed. Тест без авторизации подтверждает только доступные до входа экраны.
