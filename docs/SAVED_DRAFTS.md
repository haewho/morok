# Сохранённые черновики

В обычном доступном для отправки чате пункт `⋮` → «Сохранённый черновик» открывает отдельный локальный снимок текста для текущего аккаунта, чата и темы. Снимок не заменяет штатный draft Telegram и не синхронизируется с сервером.

Экран показывает текст, который был в редакторе при открытии, и ранее сохранённый снимок. Сохранение пустого или состоящего только из пробелов текста запрещено. Повторное сохранение и удаление требуют явного подтверждения. Первая версия сохраняет plain text до 4096 символов; formatting entities, reply/effect/webpage state и вложения остаются в штатном редакторе Telegram.

Восстановление сначала проверяет текущий message-length limit. Если редактор пуст, текст восстанавливается сразу. Если пользователь уже набрал другой текст, появляется диалог с точным предупреждением о замене. После подтверждения меняется только поле ввода через `ChatActivityEnterView.replaceWithText`; ответ, тема и остальное состояние чата не отправляются и не меняются. Пользователь проверяет результат и отдельно нажимает Send.

## Хранение и границы

- До 256 снимков на устойчивый Telegram user ID; ключ записи состоит из `dialogId` и `topicId`, метка чата ограничена 128 символами, текст — 4096, открытая база — 2 МиБ.
- На диск в `noBackupFilesDir/morok/saved-drafts/<userId>/drafts.tink` атомарно пишется только ciphertext. Используются Google Tink AEAD, отдельный Android Keystore key и account-bound AAD.
- Existing ciphertext без доступного ключа не перезаписывается. Ошибка показывается пользователю, а данные остаются закрытыми.
- Logout синхронно записывает durable revocation marker до очистки account slot, затем последовательная очередь удаляет отдельный ключ и каталог.
- Снимки не входят в Telegram database, Android backup или перенос настроек MOROK.

Пункт исключён из secret, Saved Messages, Replies/Anonymous, read-only channel и служебных режимов. Полная приёмка требует авторизованных private/group/channel/topic сценариев, restart, смены аккаунта во время I/O, key loss и logout/login другого пользователя в том же slot.
